# Android Device Tree for the itel P55 5G (P661N)

## Device Specifications

| Feature                  | Specification                                          |
|:-------------------------|:-------------------------------------------------------|
| **Chipset**              | MediaTek Dimensity 6080 (6nm)                         |
| **CPU**                  | Octa-core (2x2.4 GHz Cortex-A76 & 6x2.0 GHz Cortex-A55)|
| **GPU**                  | Mali-G57 MC2                                          |
| **Memory**               | 4GB/6GB LPDDR4X                                       |
| **Storage**              | 64GB/128GB (expandable via microSD)                   |
| **Display**              | 6.6" IPS LCD, 90Hz, 720x1612 pixels (~267 ppi)        |
| **Camera (Rear)**        | 50MP (wide) + auxiliary lens, 1080p@30fps             |
| **Camera (Front)**       | 8MP                                                   |
| **Battery**              | 5000 mAh with 18W Fast Charging (USB Type-C)          |
| **Android Version**      | Android 13, itel OS 13                                |
| **Connectivity**         | 5G (SA/NSA), 4G LTE, Dual SIM, Wi-Fi, Bluetooth       |
| **Audio**                | Loudspeaker, 3.5mm jack                               |
| **Sensors**              | Fingerprint (side-mounted), accelerometer              |
| **Colors**               | Galaxy Blue, Mint Green                                |
| **Models**               | P661N, P665L                                          |
| **Architecture**         | ARM64 (64-bit only)                                    |

Source: [GSMArena](https://www.gsmarena.com/itel_p55_5g-12604.php)
